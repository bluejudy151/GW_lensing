# Attribution and licensing

This folder contains the authors' manuscript, scientific source code, simulated data and saved experimental results. No project-wide reuse licence has been selected in the supplied project, so this snapshot does not assign one on the authors' behalf.

`manuscript/mnras.cls` is the supplied MNRAS LaTeX class. Its original notices and licence terms are retained in the file. Python dependencies are not vendored and retain their respective licences.

The citation file records the latest manuscript authors. No DOI, repository URL or publication acceptance is asserted by this archive.
